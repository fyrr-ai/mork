# Code of conduct

Treat contributors and users with respect. Discuss code and behavior with
specific evidence. Give people room to ask questions and disagree.

Harassment, threats, discriminatory remarks, sexual harassment and publishing
someone's private information without permission are unacceptable. These rules
apply in repository issues, pull requests and other project spaces.

Maintainers may remove offending content, close discussions or restrict access.
They consider the severity of the incident and repeated behavior when deciding
how to respond. The rules apply to maintainers as well as contributors.

To report an incident in a public project discussion, open an issue with a link
to the relevant content. Do not include private information. For a report that
needs private contact, use contact details the repository owner provides on
[their GitHub profile](https://github.com/tomsej). Security vulnerabilities follow
[SECURITY.md](SECURITY.md).
