# Review rules by file type

The reviewer's task lists the rules for the file types a change touches. `default.md` always applies.

These files are copied unmodified from [Open Code Review](https://github.com/alibaba/open-code-review/tree/b842659ed903743fe0afeb50eead62ca47de3deb/internal/config/rules/rule_docs) (Apache-2.0, copyright 2026 Alibaba). See [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). To add a file type, copy its document here and map it in `src/review.ts`.
